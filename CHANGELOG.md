## Versioning

EditNova Pro uses the following version format:

`MAJOR.MINOR.PATCH`

- **MAJOR:** Incompatible changes or major redesigns.
- **MINOR:** New features that maintain compatibility.
- **PATCH:** Bug fixes and small improvements.
